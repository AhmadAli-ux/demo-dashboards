# Demo Dashboards — Deploy Guide

3 demo dashboards, sab Python (Streamlit + Plotly + pandas + NumPy), sab sample data pe.
Har folder me `app.py` + `requirements.txt` hai.

## Deploy (Streamlit Community Cloud — free)

1. GitHub pe ek repo banao, e.g. `demo-dashboards`, aur teeno folders push karo.
2. share.streamlit.io → New app → repo select karo → Main file path:
   - `d2c-growth-dashboard/app.py`
   - `ecommerce-product-dashboard/app.py`
   - `clinic-bookings-dashboard/app.py`
3. Deploy dabao — har app ka apna public link milega.
